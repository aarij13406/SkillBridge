## Dataset Setup

The complete dataset is distributed separately because of its size and is not stored in the Git commit history.

### Download

1. Open the latest GitHub Release:

   https://github.com/aarij13406/SkillBridge/releases/latest

2. Download `data.zip`.

3. Extract the ZIP file into the root project directory.

The final structure should be:

```text
SkillBridge/
|-- data/
|   |-- raw/
|   |-- processed/
|-- figures/
|-- results/
|-- scripts/
|-- skillbridge/
|-- README.md
|-- requirements.txt
